# Data Science & Machine Learning Portfolio

Репозиторий представляет собой портфолио практических кейсов в области классического машинного обучения, интеллектуального анализа данных и предиктивного моделирования. 

Каждый проект оформлен как полноценное исследование: от разведочного анализа и предобработки сырых данных до оптимизации гиперпараметров, валидации и интерпретации готовых моделей.


### Используемые модели и алгоритмы

**Обучение с учителем**
* **Классификация и регрессия:**
  * kNN
  * Linear Regression
  * Logistic Regression
  * Naive Bayes
  * Decision Tree
  * SVM
* **Ансамблевые методы:**
  * Random Forest
  * Gradient Boosting (XGBoost / LightGBM / CatBoost)

**Обучение без учителя**
* **Кластеризация:**
  * K-Means
  * DBSCAN
* **Снижение размерности и визуализация:**
  * PCA
  * t-SNE
  * UMAP
